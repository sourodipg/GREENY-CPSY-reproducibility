# How to interpret this experiment

The parent GREENY process is an exogenous directed influence process. The extension does not call one participant an "actor" and the other a "partner" for the symmetric event. For analysis, "participant 1/participant 2" are used for the unordered encounter.

The primary causal contrast is **matched bidirectional sequential** versus **matched symmetric simultaneous**. Each condition uses the exact same unordered encounter ledger, same population seed, same forcing realization, and the same participant update count (two participant updates per unordered encounter). The only difference is whether both responses are computed from the common pre-event state and committed together (simultaneous) or the second participant sees the first participant's newly updated belief (sequential).

This is deliberately narrower than comparing GREENY with the extension, because it avoids conflating reciprocity/simultaneity with a different interaction-topology process. GREENY is retained as a network-structure reference.

The network diagnostics therefore ask whether state coupling emerges on a shared encounter graph: repeated-partner rates, same-family exposure, mutual elevation at encounter, pre- and post-event pair-state concordance, and parent-vs-matched graph properties.

The design follows the Social Relations Model distinction between actor, partner, relationship and family components (Cook & Dreyer, 1984; An et al., 2023) and the dynamic-network literature's separation of reciprocity, transitivity, and covariate effects (Snijders, 2017). Common random-number pairing is used as a variance-reduction strategy for stochastic system comparisons (Yang & Nelson, 1991).
