# Dynamic network analysis

The extension treats the interaction graph as a time-indexed graph G_t. The parent GREENY process is a directed independent-draw process; the extension uses an exogenous perfect-matching encounter ledger.

We do not claim that the matching process discovers friend groups. Without adaptive tie formation, community detection can manufacture structure or merely rediscover imposed family labels. Instead, the high-signal diagnostics are:

- one-step, 5-step and 20-step same-partner recurrence;
- mutual-elevation probability at encounter;
- pair-state concordance for x and normalized debt;
- concentration of encounter counts.

If the symmetric mechanism creates social structure through state coupling alone, the matched-directed and matched-symmetric conditions should share exactly the same encounter graph but differ in pair-state statistics. That is the clean test.

For actual network-formation hypotheses (reciprocity preference, triadic closure, homophily, partner choice), a separate adaptive network model would be required. This follows the standard logic of stochastic actor-oriented network models, which explicitly distinguish structural effects such as reciprocity/transitivity from actor and dyadic covariates.
