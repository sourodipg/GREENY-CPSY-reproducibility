# Self-aware GREENY structure audit

This release distinguishes **software PASS** from **scientific invariance**.

A structural audit can establish that a test was implemented and executed correctly without establishing that an observed scientific effect is invariant to every modelling choice.

## Established by the suite

- One-sided recipient designation is reproducible and approximately balanced.
- Metric-local matching uses the rank ordering of a fixed exogenous coordinate.
- A strictly increasing transformation such as `z -> z^3` leaves the metric contact ledger unchanged.
- Extreme recurrence is generated by the contact rule itself, before GREENY state dynamics are run.
- The coordinate is generated independently of attachment and the production random-contact cells do not depend on the coordinate offset.

## Deliberately left open

Changing the coordinate **realization** changes which agents occupy the imposed local neighbourhoods. It can therefore change the M D-to-Y contrast even when recurrence remains approximately one-half immediately and extremely high over longer horizons.

That is a scientific sensitivity finding, not a software failure. The suite reports `SENSITIVITY_DETECTED` rather than falsely reporting a generic PASS.

## Interpretation

The recurrent-local experiment is an **imposed recurrent-exposure experiment**. It should not be interpreted as evidence that agents naturally choose one another, form attachment, or endogenously create a social network.

The state-update equations can create pair-state coupling under repeated exposure. That is distinct from natural relationship formation.

## Next manuscript step

No manuscript claim is automatically changed by this package. Results should be incorporated only after the coordinate-realization sensitivity has been considered in the final interpretation.

## One-sided recipient ordering

The D selector is approximately balanced between the two members. A stronger audit also checks whether the physical recipient is invariant to reversing the ordered representation of the same pair. The present selector is representation-sensitive in that stronger sense. That finding is retained explicitly because changing the selector would alter the archived numerical results and would require a fresh production rerun.

## One-command audit

```bash
./verification/run_reviewer_audit.sh
```

The fast audit is intentionally non-blocking on scientific sensitivity findings. A coordinate-realization result of `SENSITIVITY_DETECTED` is expected to be treated as a finding for interpretation rather than a failed software test.

For a stronger coordinate-realization stress test, run:

```bash
make coordinate-audit-production
```

This uses 12 seeds and four coordinate realizations and should be regarded as an optional production-scale sensitivity analysis rather than a fixture test.
