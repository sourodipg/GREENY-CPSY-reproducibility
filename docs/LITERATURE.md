# Structural literature anchors

The experiment does not claim that the metric contact rule is an established psychological law. It is an exogenous network stress-test designed to distinguish well-mixed from locally constrained contact.

For dyadic/actor-partner structure, see work using actor–partner and family/relationship decompositions in couple data, e.g. An et al. (2023). The present experiment uses those ideas as a structural motivation, not as a numerical validation target.

For reproducibility/software structure, see `SOFTWARE_PRACTICES.md`.
