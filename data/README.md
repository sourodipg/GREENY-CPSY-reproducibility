# Released data

These directories contain the machine-readable results used for the manuscript's reported analyses.

- `primary/`: primary four-cell matched network experiment summaries and seed-level results.
- `branchN/`: 24 coordinate-realization × 12-seed structural sensitivity summaries.
- `interaction_disambiguation/`: 56-seed interaction counterfactual results for D, Y, recipient swap, partner-signal ablation and half-alpha updating.
- `network/`: temporal/exposure-network summaries and realization-level graph statistics.

The simulation seed is the inferential replicate. Agents, encounters and time points are not treated as independent observations.

CSV files are retained as plain text so that they can be inspected without specialized software.
