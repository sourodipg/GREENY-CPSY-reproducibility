# Released result index

## Primary experiment

`primary/matrix_per_seed.csv`, `primary/matrix_summary.csv`, and `primary/differences.csv` contain the four matched cells and derived contrasts used by the primary analysis.

## BranchN coordinate-realization sensitivity

`branchN/branchN_by_seed.csv` contains the realization-by-seed results; `branchN_by_offset.csv` contains realization-level summaries; `branchN_report.md` explains the estimands and interpretation; `branchN_summary.csv` records the top-level summary.

Design: 24 coordinate realizations × 12 seeds = 288 trajectories.

## Interaction disambiguation

`interaction_disambiguation/interaction_disambiguation_per_seed.csv` contains the five counterfactual conditions across two contact regimes and 56 seeds. `interaction_disambiguation_contrasts.csv` contains the matched contrasts. The run logs document the execution and integrity checks.

## Temporal/exposure network

`network/` contains realization-level network metrics and the literature-grounded temporal/exposure network report.
