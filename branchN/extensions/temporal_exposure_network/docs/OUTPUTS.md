# Outputs

`network_metrics_by_seed.csv` contains one row per offset×seed graph instance.

`network_metrics_by_offset.csv` averages the standard graph and mixing quantities over the 12 seeds for each of the 24 coordinate realizations.

`network_metric_effect_correlations.csv` correlates those realization-level graph summaries with the already-generated BranchN `M_Y-M_D` contrasts for `rA` and `rV`. It is explicitly exploratory.

`temporal_network_report.md` is the noob-proof prose report.
