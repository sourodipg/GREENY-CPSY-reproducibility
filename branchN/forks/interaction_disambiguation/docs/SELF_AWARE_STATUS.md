# Self-aware status

## Scope
This fork extends BranchN without modifying the parent GREENY source or replacing any prior results. It re-simulates the interaction rule on the same contact ledgers so the unresolved update-rule confounds can be tested directly.

## Already-established upstream evidence in this package
The package already contains construction/ratio audits, generator forcing checks, partner-order replay, random recurrence benchmarking, recurrent-local manipulation checks, latent-coordinate independence and rank-invariance checks, recipient-balance audit, the 56-seed matched one-sided/two-sided experiment, simultaneous-versus-sequential control, anxiety-assortative boundary condition, local 10% parameter sign-stability, the 24-coordinate-realization BranchN audit (288 trajectories), neighborhood trait-composition analysis, literature-grounded temporal/exposure-network analysis, graph-kernel invariants, numerical claim reconstruction, sanitizer execution, and package preflight/self-checks.

## New fork
The new interaction fork adds three direct counterfactuals: recipient-swapped one-sided updating, partner-signal-ablated two-sided updating, and two-sided updating with half the per-update assimilation fraction.

## What has been verified here
The separate fork executable compiles with GCC using `-Wall -Wextra -Wpedantic -Werror -fopenmp`. A two-seed smoke run completed. The validator confirmed finite outputs, all five conditions, the expected 2x2x5 row structure, identical encounter-ledger digests within each seed/contact regime, explicit condition metadata, and the declared ablation/intensity settings.

## What has NOT been done here
The full 56-seed x 2-contact-regime production run has not been executed in this environment. The results currently present in `results/` are smoke-test outputs and must not be cited as production findings.

## Interpretation rule
The fork is a disambiguation experiment, not an automatic causal decomposition. Any manuscript claim must be based on the full production seed-level results after the validator passes.
