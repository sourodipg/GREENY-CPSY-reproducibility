# BranchN interaction-disambiguation fork

Additive fork for the already completed BranchN experiment. Parent GREENY implementation and parent outputs remain unchanged.

The fork re-simulates the exact encounter ledgers for five interaction conditions under random and recurrent-local contact:

`D`, `Y`, `D_SWAP`, `Y_ABLATE`, `Y_HALFALPHA`.

Purpose: identify whether the primary D-to-Y shift is sensitive to recipient designation, the cross-partner state signal, or reduced per-update assimilation magnitude.
