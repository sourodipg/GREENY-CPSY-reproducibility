# GREENY targeted test suite

This suite is designed around the highest-value hidden assumptions raised during review. It does not modify the manuscript.

## Fast structural audit

```bash
make verify
```

This includes the ordinary unit/invariant tests and the network-structure audit.

The structural audit checks:

1. **One-sided designation balance.** The D-condition recipient selector is reproducible and approximately balanced between pair members over a large deterministic audit set. A separate order audit also reports whether the selector changes when the same physical pair is passed in reversed representation order.
2. **Latent-rank invariance.** Replacing `z` by the strictly increasing transform `z^3` leaves the rank ordering and metric contact ledger unchanged.
3. **Direct recurrence construction.** The metric-local contact rule itself, without the GREENY state dynamics, produces the expected strong recurrence at 1, 5 and 20 encounter horizons.

## Coordinate-realization audit

This isolates the effect of changing only the realization of the exogenous local coordinate. Population and forcing seeds are held fixed while `coordinate_seed_offset` changes.

Default production-scale audit:

```bash
python3 verification/coordinate_realization_audit.py
```

For a quick run:

```bash
python3 verification/coordinate_realization_audit.py \
  --seeds 2 --threads 2 --families 20 --steps 400 --n 80 \
  --offsets 0 1 2
```

Interpretation:

- Random-contact cells must be exactly unchanged across coordinate offsets.
- Metric-contact cells may change because only the imposed local neighbourhoods change.
- `M_repeat1` should remain near one-half for every offset.
- The metric D-to-Y contrasts are recorded descriptively; no arbitrary pass/fail threshold is imposed on the scientific effect.

## Self-aware interpretation

The structural and coordinate audits separate **implementation validity** from **scientific invariance**. In particular, `coordinate_realization_audit.py` may complete successfully with `status=SENSITIVITY_DETECTED`. This means that the audit ran correctly and found that the M D-to-Y contrast changes when only the exogenous local-coordinate realization changes. It is not a failure of the software; it is a reviewer-facing sensitivity result.

The recurrent-local construction is an imposed contact cage: repeated contact is generated by the contact kernel itself. It is not evidence of naturally emergent attachment or voluntary partner retention.

Run:

```bash
python3 verification/coordinate_realization_audit.py
python3 verification/reviewer_gap_report.py
```

## One-sided order audit

```bash
python3 verification/directed_recipient_order_audit.py
```

The production selector is approximately balanced, but if reversing `(i,j)` to `(j,i)` can change the selected physical recipient, that is reported as an implementation finding. It is not silently changed in this release because changing the selector would change the archived 56-seed numerical results and would require a fresh production rerun.
