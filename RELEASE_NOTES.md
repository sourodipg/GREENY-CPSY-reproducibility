# GREENY v1.0.0

This release contains the reproducibility record accompanying the GREENY computational-psychiatry manuscript.

Included are the production model source, parent-core provenance, verification tests, primary seed-level results, BranchN coordinate-realization sensitivity results, temporal/exposure-network analysis, interaction-disambiguation counterfactuals, manuscript, supplement and citation metadata.

The release does not claim clinical validation or an empirically calibrated social network. Its purpose is transparent interrogation and reproducibility of the specified generative model.
