# Contributing

The repository is primarily an archival reproducibility record for the GREENY manuscript.

Changes to the scientific model should not be made silently. A proposed model change should identify the affected equations, parameters, tests, experiment manifests and manuscript claims. New results should be accompanied by machine-readable seed-level output and an explicit description of the inferential unit.

Changes intended only to improve documentation, portability or tests should be kept separate from scientific model changes where practical.
